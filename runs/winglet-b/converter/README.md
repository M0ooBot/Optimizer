# Converter MCP workspace

The [Airfoil Converter MCP server](../CONVERTER_TOOLS.md#converter-mcp-server) writes here and nowhere else: curve files, `.dat` profiles, `build_law` sets and its `*.airfoils.json` project records. Only this README is tracked; the server's output is not, as with the rest of `runs/`. Commit anything worth keeping with the study that used it.
